I used AI as a learning helper while working on this project. I reviewed the suggestions and made the final decisions and changes myself.

## Tailwind CSS
AI helped me learn how to:
- Install and use the Tailwind CSS CLI.
- Set up input.css and generate output.css.
- Use the @source directive.
- Use Tailwind utility classes, responsive classes, dark colors, gradients, spacing, borders, and hover states.
- Use --watch while editing and --minify for the final build.
## Git and GitHub
AI helped me understand:
- How to initialize a repository and connect it to GitHub.
- The purpose of .gitignore and untracked files.
- How to stage, commit, pull, and push changes.
- How to configure Git author details.
- How to keep .env and API keys out of GitHub.

## Deployment
AI helped explain:
- Why Gunicorn is used when deploying the app.
- Render build and start commands.
- Environment variables and secrets on a hosting service.
- Free hosting limits, cold starts, and in-memory data.
